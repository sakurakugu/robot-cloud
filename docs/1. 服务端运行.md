# 服务端运行

本文档描述 `robot-cloud` 当前实际可用的开发与部署运行方式。

## 当前组件

`robot-cloud` 现在不只是单个 Node 服务，而是这几部分协同：

- 前端：Vue 3 + Vite
- 后端：Node.js + Express + WebSocket
- 数据库：PostgreSQL
- 媒体：mediamtx
- 穿透：coturn
- 反向代理：nginx

## 开发模式推荐入口

统一使用：

```bash
python tools/1.启动服务端.py
```

默认行为是 `restart`。

常用命令：

```bash
python tools/1.启动服务端.py --start
python tools/1.启动服务端.py --stop
python tools/1.启动服务端.py --restart
python tools/1.启动服务端.py --status
python tools/1.启动服务端.py --db-upgrade
```

## 开发模式会启动什么

当前开发脚本会同时拉起：

- Docker 依赖：`postgres`、`mediamtx`、`coturn`
- 本地后端热更新
- 本地前端热更新

## 默认端口

- 前端：`5174`
- 后端：`9000`
- 后端健康检查：`http://localhost:9000/api/v1/health`
- 前端媒体代理：`http://localhost:5174/media/`

## 首次启动前建议确认

```bash
docker --version
docker compose version
node -v
```

应满足：

- Docker / Docker Compose 可用
- Node.js `24.x`

## 环境变量

开发脚本会优先读取：

- `.env`
- 如果缺失，再尝试使用 `.env.example`

当前核心变量包括：

- `PORT`
- `DB_HOST`
- `DB_PORT`
- `DB_NAME`
- `DB_USER`
- `DB_PASSWORD`
- `WS_ROBOT_PATH`
- `WS_PHONE_PATH`
- `WS_WEB_PATH`
- `MEDIA_STREAM_PATH_PREFIX`
- `MEDIA_WHEP_BASE_URL`

## 手动分开启动

### 启动后端

```bash
cd 后端
npm install
npm run dev
```

### 启动前端

```bash
cd 前端
npm install
npm run dev
```

### 数据库迁移

```bash
cd 后端
npm run migration:up
```

## Windows 防火墙

记得修改防火墙入站规则，

1.  按下"Win键"，搜索"防火墙"
2.  打开"高级安全Windows Defender防火墙"，找到左边"入站规则"
3.  添加"端口"，选择TCP、端口：9000-9100, 名称：".AAA机器狗开发"

## 生产模式

脚本支持生产模式：

```bash
python tools/1.启动服务端.py --prod --start
python tools/1.启动服务端.py --prod --status
python tools/1.启动服务端.py --prod --db-upgrade
```

仓库也保留了：

```bash
bash ./start.sh
```

## 当前推荐排障顺序

遇到问题时，优先按下面顺序查：

1. `python tools/1.启动服务端.py --status`
2. 查看后端健康检查 `http://localhost:9000/api/v1/health`
3. 查看 Docker 容器是否正常
4. 再看前端页面、数据库迁移和媒体链路
